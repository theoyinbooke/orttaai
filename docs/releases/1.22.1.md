# Orttaai 1.22.1

Released November 19, 2026.

Orttaai 1.22.1 makes dictation quicker to finish and harder to miss.

## Faster

- **The speech model loads as you start talking.** If it wasn't ready (after changing the dictation language, say, or right after launch), it used to load when you released the key, so you waited for it. Now it loads while you're still speaking.
- **Long dictations finish sooner.** With Express, each pause in a long dictation started another decode of everything so far, and they queued up for the end. Now a pause waits for the one before it to finish, so the decode when you let go doesn't wait behind a pile of them.

## Fixes

- **A key press while a message is showing works.** After "Some audio was lost" or "Couldn't insert text", the dictation and edit keys were ignored for the two seconds the message stayed up. Now a press clears the message and starts recording.
- If Express can't load during a dictation, Orttaai uses Whisper and tells you once, instead of trying Express a second time when you release the key.
