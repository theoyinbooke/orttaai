# Orttaai 1.21.0

Released November 10, 2026.

Orttaai 1.21.0 makes editing what you said as quick as saying it: one key to start an edit, or no special key at all.

## Edit without the three-key shortcut

- **Tap Right Command to edit.** Tap it, say how to change your text ("make this more formal"), and tap it again. Turn it on in Settings › Text › Voice Editing. ⌘ shortcuts still work as usual: only a brisk tap on its own counts. Like Tap Right Option, it needs Input Monitoring.
- **Your dictation shortcut edits a selection.** Select text, press your dictation shortcut and say an instruction like "make this shorter", "fix the grammar" or "turn this into a list". Anything else you say replaces the selection, as before. The rules are strict on purpose: "put it on the calendar" is still typed. English only, and only in apps that let Orttaai read the selection; elsewhere use an edit key. Turn it off in Settings › Text.
- **Edit your last dictation with nothing selected.** Right after dictating, press an edit key and say "make that more formal". Orttaai finds what it just typed in that app (within 10 minutes), selects it and rewrites it. Edit the result again the same way.
- Ctrl+Shift+E still works, and you can change it in Settings › Text.

## Careful by default

- Without a local model running (Ollama or LM Studio), the dictation shortcut types your words exactly as in 1.20.
- An edit that doesn't land never loses your words: they're saved to History, and text Orttaai selected for an edit is put back as it was.
- If the selection changes while you speak the instruction, nothing is pasted beside it.
- Browser address bars and search boxes, terminals and password fields are never edited from the dictation shortcut.
- In VS Code, Cursor and Windsurf, an edit with nothing selected no longer rewrites the line the cursor is on.
