# Orttaai 1.11.0

Released October 4, 2026.

Orttaai 1.11.0 improves dictation accuracy and makes downloaded updates easier to install.

- Accuracy now starts with greedy decoding while keeping the standard quality fallbacks.
- Live transcription splits clips at nearby quiet gaps and retains quiet word endings, reducing words lost or duplicated at clip boundaries.
- Speech remains available for recovery when a background decode unexpectedly returns empty text.
- On the 36-item synthetic noisy-audio benchmark, Balanced word error rate fell from 7.50% to 3.51% (154 errors to 72); median finalization improved from 724 ms to 621 ms. Results vary by speaker, microphone, and hardware.
- Downloaded updates can be installed and relaunched with the **Update** button in the sidebar. Install-on-quit remains available.
- About now includes **Automatically download updates**, backed by Sparkle's existing preference.
- The internal build version follows the displayed version, preventing an installation from being offered the version it already has.

Download the DMG, open it, and drag Orttaai into Applications. Existing direct-download installations can use **Check for Updates**. Homebrew installations update with `brew upgrade --cask theoyinbooke/orttaai/orttaai`.

Validation: 677 tests passed, 7 skipped, and no failures. Live Codex/Grok integration tests and UI automation were excluded.

Universal Apple Silicon and Intel build, signed with Developer ID, notarized by Apple, and stapled. Production iCloud entitlements and the updated distribution provisioning profile are included.

The app inside the DMG passed strict signature verification and Gatekeeper assessment as **Notarized Developer ID**.
