# Orttaai 1.11.1

Orttaai 1.11.1 keeps hands-free dictation running while you speak softly and no longer saves text meant for password fields.

- Hands-free dictation no longer stops while you are still talking quietly. Stop After Silence now judges silence against your room's background noise instead of a fixed loudness level, so soft speech keeps the recording going. It never stops sooner than before, and a steady fan or noisy room still lets it stop.
- A dictation blocked because the focused field is a password field is no longer saved to History or synced to iCloud.
- The Grok setting now describes what is sent to Grok: Chat AI, writing insights, tone profile, and graph summaries. Dictation polish and voice edits always stay on your Mac.
- The README now lists the correct minimum macOS version (14.6), current model download sizes, the real recording limits, and every current feature.

Download the DMG, open it, and drag Orttaai into Applications. Existing direct-download installations can use **Check for Updates** or the **Update** button in the sidebar. Homebrew installations update with `brew upgrade --cask theoyinbooke/orttaai/orttaai`.

Validation: 687 tests passed, 9 skipped, and no failures. Live Codex/Grok integration tests and UI automation were excluded. A soft-spoken hands-free recording of more than two minutes was tested on a Developer ID-signed build.
